# Abhinav Mangam — Portfolio

A responsive, white/minimal editorial-style portfolio for an Oracle Fusion HCM Technical Consultant.

## Run locally
This is a static website. Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy free with GitHub Pages
1. Create a GitHub repository named `abhinavmangam.github.io` (or use another repository).
2. Upload the contents of this folder to the repository root.
3. For a project repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`.
4. Wait for the deployment URL shown in GitHub Pages settings.

## Before publishing
- Confirm all personal details and project descriptions.
- Add your latest resume as `resume.pdf` only when ready, then add a download link in `index.html`.
- The contact form uses `mailto:` and opens the visitor's email application. It does not store submissions. Connect a form service if you need server-side form handling.
- The Employee Data Integration & Validation project is labelled as a concept/planned implementation.
- HDL generation in FusionForge is described as present in the codebase but not yet a complete frontend workflow.
- Confidential projects have no repository links or downloadable files.
- Replace or remove any content that no longer reflects your current work.
